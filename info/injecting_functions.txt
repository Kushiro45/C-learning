SORTING using function pointers:

C standard library has a sort function that accepts a pointer to a comparator
function, which is used to determine if a piece of data is same, less or  greater
than another piece of data: qsort()

qsort(void *array, size_t length, size_t item_size, int (*compar)(const void *, const void *));

parameters: pointer to an array, a var storing length with size_t datatype so technically can store very big ones
item_size is size of each element. and finally a pointer to an int function which accepts two void pointers that can point to anything

qsort will switch values in wrong order and comparator will tell it which is the wrong order

val1 > val2 = +num
val1 < val2 = -num
val1 = val2 = 0

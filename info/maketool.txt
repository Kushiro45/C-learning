MAKE TOOL:
make is a tool that can run the compile command by checking the timestamps
of source and object files, and recompiles the updated source files.
basically automation.
(NOTE: in windows MinGW has  mingw32-make and Microsoft has their own
 version called NMAKE)
Every file that make compiles is called a target. it isnt limited to compiling files
a target is any file that is generated from some other files.
so a target might be a zip file generated from the set of files that need to be
compressed

for that make requires two things.
1) The dependencies - Files the target is going to be generated from
2) The instructions(recipe) - set of instructions it needs to run to generated the file
together these form a 'rule'

eg.
gcc -c thruster.c -------> thruster.o
-----------------		^---------- target
	^--------- rule for creating thruster.o

similary one can also make the final program executable since its also a taret file
we want to generate
the dependencies will be the object files .o

NOTE-> to find dependencies you can run gcc -m filename
or simply look at the include files along with source code, thats the dependencies
for the particular object file.

it must also be noted that the file will be recompiled even if a comment is added
and even if the rest of the thing is untouched.

---> if you write a makefile for windows machine its not necessary to work on others
because it calls underlying commands from the operating system.

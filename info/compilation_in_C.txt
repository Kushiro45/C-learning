1) Preprocessing
Compiler preprocesses the source and adds  extra header files to the source code
mentioned in the #include section
2) Compilation
The source code gets translated into assembly
assembly language describes the individual instructions the central processor
will have to follow when running the program
3) Assembly: Generate object code
The compiler will assemble the symbol code(assembly) into machine or object code
This is the binary that will be executed inside the CPU circuits
IF there were several files to compile for the program then for each file 
a piece of object code is generated by the compiler. hence ->
4) Linking: (putting it all together)
The compiler will connect the code in one piece object code that calls a function to another
piece of object code. linking also make sures that program is able to call 
lib code. finally the program will be written in an executable program file
supported by the OS. (format is important)
